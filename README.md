Installation
Install the required libraries by running:
pip install osmnx networkx matplotlib jupyter
How to Run
1. Download or clone the project files.
2. Open the Jupyter Notebook or Python script.
3. Ensure you have an active internet connection to download road data.
4. Run the code from the beginning.
5. Update the starting point and destination coordinates if needed.
6. View the calculated route and map.
Dataset
The project uses road network data from OpenStreetMap.
- OpenStreetMap: https://www.openstreetmap.org/
- OSMnx Documentation: https://osmnx.readthedocs.io/
Applications
- Route planning demonstrations
- Road network analysis
- Shortest-path algorithm learning
- Network optimization experiments
Limitations
Travel times are estimates and do not include guaranteed live traffic information. Results depend on OpenStreetMap data availability and accuracy.
